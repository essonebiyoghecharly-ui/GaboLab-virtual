# LabGabon V6 — Laboratoire intelligent

## Démarrage

```bash
python -m http.server 8000
```

Ouvrir `http://localhost:8000`.

## Nouveautés

- connexion de matériels en mode électrique ;
- validation de montages ;
- retours pédagogiques ;
- TP guidé de filtration ;
- recherche du matériel ;
- annulation et suppression ;
- sauvegarde IndexedDB ;
- mode hors connexion PWA ;
- export CSV ;
- clic et glisser-déposer.

Double-cliquez dans la paillasse pour activer le mode connexion, puis cliquez sur deux matériels.
